# Power BI Projects

This repository contains Power BI dashboards, data resources, documentation, and analysis projects focused on turning business data into useful insights. Each project is organized in its own folder and may include source data, Power Query transformations, DAX measures, report assets, and project notes.

## Projects

### [Walmart Sales Dashboard](Walmart-Sales-Dashboard/)

An interactive retail sales analysis covering products, customers, stores, employees, transaction dates, payment methods, revenue, quantities, and shipping costs.

### [E-Commerce Store Sales Analysis](E-Commerce-Store-Sales-Analysis/)

A Power BI project for exploring e-commerce sales performance, customer behavior, product performance, store results, and key business metrics.

## Project Structure

Each project should keep its related resources together, including:

- A project-specific `README.md`
- Source data and data dictionaries
- Power BI reports and supporting assets
- Documentation for calculated measures and important assumptions

## Tools and Technologies

- Power BI Desktop
- Power Query
- DAX
- CSV and other structured data sources

## Purpose

The goal of this repository is to maintain a clear, reusable collection of Power BI work while documenting the data model, analytical goals, and insights behind each dashboard.
