# E-Commerce Store Sales Analysis

This project provides an interactive Power BI dashboard for analyzing e-commerce store sales performance. It is designed to turn transactional and business data into clear insights about revenue, orders, products, customers, stores, and employees.

The analysis can be used to identify sales trends, compare performance across stores and product categories, understand customer behavior, and support data-driven decisions. The dashboard will combine well-structured data with interactive visuals, filters, and key performance indicators to make important business metrics easy to explore.

## Project Goals

- Track sales and order performance over time
- Identify high-performing products, stores, and employees
- Analyze customer purchasing patterns
- Compare business performance across relevant dimensions
- Present actionable insights through an intuitive Power BI report

## Tools

- Power BI Desktop
- CSV data sources
- Power Query for data preparation
- DAX for calculated measures and analysis
